# Herkunft

HarborDash basiert auf [sandavdesigns/homebase](https://github.com/sandavdesigns/homebase),
Stand `main` beim Kopieren am 10. November 2026. Die ursprüngliche Git-Historie
und die ursprünglichen Autoren bleiben erhalten.

Die Dashboard-Oberfläche, Profile, Themes, Widgets, Import-/Export-Funktionen,
Integrationen und Favicon-Verwaltung stammen überwiegend aus Homebase.
HarborDash ergänzt verpflichtende Authentifizierung, dauerhafte Geräte-Sitzungen,
Geräteverwaltung, Sicherheitsprüfungen und ein angepasstes Deployment.

Im übernommenen Repository lag keine LICENSE-Datei. Deshalb wird hier keine neue
Lizenz für den übernommenen Code behauptet; das frühere MIT-Image-Label wurde entfernt.
